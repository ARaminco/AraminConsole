# AraminConsole modules

Optional, self-contained features that sit on top of the core bundle. One folder per module: `src/modules/<name>/<name>.js` + `<name>.css`.
Contract (so they can be bundled per module or imported directly):

- No `import` of core files. Each module exports `install(AC)` and calls it automatically when `window.AC` exists.
- `install(AC)` adds `AC.<name>(el, cfg)` and registers `data-ac="<name>"` through `AC.register`.
- Until per-module bundling lands, the module injects its own stylesheet once (`<link data-ac-module="<name>">`, resolved from `import.meta.url`).
- Tokens only; logical properties; every interactive element has hover / active / focus-visible states.

## Bundling (platform)
Per-module bundling has landed — see `docs/modules.md`. Every folder here is discovered by `scripts/build.mjs`: it is part of the
full bundle (`"bundle": false` in an optional `module.json` opts out), gets `dist/modules/<name>.{js,css}` (+ `.min`) for `AC.use('<name>')`,
and can be picked for custom builds (`--modules=` / `aramin.config.json`). `module.json` (optional): `{ "description", "dependencies": ["overlays"], "bundle" }`.
Bundled code sees `import.meta.url` pointing at `dist/modules/`, so `new URL('./<name>.css', import.meta.url)` always resolves to a real file.
