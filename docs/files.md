# Files — file, document and records manager

A Finder / File Explorer-class manager as a module: `src/modules/files/` (`files.js`, `files.css`, `files-icons.js`,
`files-adapter.js`, `files-preview.js`, `module.json`). Demo: `demo/#/files` (sample content in `demo/content/files/`,
regenerated by `node tests/make-files-content.mjs`). Tests: `node tests/files.mjs --base=http://localhost:5178`;
screenshots: `node tests/files-shots.mjs`.

```js
await AC.use('files');                       // or the full bundle / import { install } from 'src/modules/files/files.js'
const fm = AC.files('#files', {
  adapter,                                   // storage adapter (below); default: an empty in-memory adapter
  id: 'docs',                                // persists view, sort, group, icon size, column widths, panes (ac:files:<id>)
  view: 'icons',                             // icons | list | columns | gallery  (phones: list | icons | gallery)
  start: 'root',                             // first location (phones default to the Browse screen '@browse')
  favorites: ['contracts', 'finance'],       // folder ids pinned in the sidebar
  calendar: 'auto',                          // auto (Jalali in fa) | persian | gregory
  iconSize: 76,                              // 48–128, also the status-bar slider
  docTypes: ['قرارداد اجاره', 'فاکتور'],     // suggestions for the "Document type" field
});
fm.go('@starred'); fm.open(id); fm.select([ids]); fm.setView('list'); fm.quickLook(id); fm.info(true);
fm.upload(fileList, folderId); fm.rename(id); fm.trash(ids); fm.refresh(); fm.selection; fm.state; fm.destroy();
```
Declarative: `<div data-ac="files"></div>` (empty in-memory adapter). The element gets `.ac-fm`; give it a height with
`--fm-h` (desktop/tablet). On phones it flows with the page (window scroll, sticky large title).

## Storage adapter
Every method is async (returns a Promise) and returns plain objects. Only `list` and `stat` are required; missing
methods hide the matching UI. `AC.files.memoryAdapter(seed, opts)` is the reference implementation.

| Method | Returns | Notes |
|---|---|---|
| `info()` | `{ root, name }` | id of the root folder |
| `list(id)` | `Entry[]` | a folder's children, or a virtual list: `@recent`, `@starred`, `@shared`, `@trash`, `@tag:<tagId>` |
| `stat(id)` | `Entry` | must include `path: [{ id, name }]` from the root (breadcrumbs, Get Info "Where") |
| `read(id, { peek })` | `{ kind, url?, text?, poster? }` | `kind`: `image pdf video audio text office none`. `peek: true` must not touch "last opened" (thumbnails) |
| `thumbnail(entry, size)` | `url \| null` | optional server rendition (PDF first page, Office render, video poster). `null` → the UI renders one |
| `upload(folder, file, { onProgress(loaded, total), signal, isPaused(), conflict, name, url })` | `Entry` | `conflict`: `replace` (new version) \| `keep` (unique name). Honour `signal` (cancel); `isPaused` only if `capabilities.pause` |
| `exists(folder, name)` | `id \| null` | used for conflict detection (falls back to `list`) |
| `mkdir(folder, name)` | `Entry` | |
| `rename(id, name)` | `Entry` | throw `{ code: 'EXIST' }` on a clash, `{ code: 'EINVAL' }` for bad names |
| `move(ids, folder)` · `copy(ids, folder, { suffix })` | `Entry[]` | refuse moving a folder into itself |
| `compress(ids, folder, name)` | `Entry` | |
| `trash(ids)` · `restore(ids)` · `remove(ids)` · `emptyTrash()` | `true` | `remove` is permanent |
| `search(query, { scope, kind, date, size, tag })` | `Entry[]` | `scope` = folder id or null (everywhere); `kind`: `folder document pdf image video audio xls zip`; `date`: `today week month year`; `size`: `small medium large` |
| `share(id, { expires (days, 0 = never), password, permission })` | `{ url, expires, password, permission }` | |
| `versions(id)` · `restoreVersion(id, versionId)` | `[{ id, date, size, by, current? }]` · `Entry` | |
| `activity(id)` | `[{ action, at, by }]` | actions: upload create rename move copy trash restore share edit replace compress restoreVersion sign review view |
| `update(id, patch)` | `Entry` | `starred tags comment doc status ocr shared color` |
| `tag(ids, tagId, on)` | `true` | bulk tagging |
| `tags()` · `users()` · `locations()` · `freeSpace()` | | sidebar tags `{ id, name, color, count }`, people `{ id, name, email, color }`, storage `{ id, name, icon, used, total, root? }` |

`capabilities: { pause, versions, share, tags, trash, search, upload, comments }`. Names of tags, users and locations
may be `{ fa, en, ar }`.

**Entry**: `{ id, name, kind: 'file'|'folder', type, parent, size, created, modified, opened, path, count (folders),
tags: [tagId], starred, shared: [{ user, role: 'owner'|'editor'|'commenter'|'viewer' }], comment, url, thumb, duration (s),
dims: [w, h], glyph (folder emblem: docs money id lock scan code media images archive shared download), color (folder tint),
doc: { type, number, date, parties, expiry, remind }, status: 'draft'|'review'|'approved'|'signed', ocr: 'done'|'pending'|'' }`.
`type` is derived from the extension when absent (`typeOf(name)`: folder pdf doc xls ppt image video audio zip code txt unknown).

A REST adapter is a thin mapping — see `demo/content/files/files-adapter.js` for a sketch.

## Content previews (real thumbnails)
Order: `adapter.thumbnail()` → client rendering from `adapter.read(id, { peek: true })`, cached per id + modified date,
loaded lazily by one `IntersectionObserver`:
- images — decoded and downscaled on a canvas (≤ 360 px, WebP blob URL); SVG used as is;
- video — a frame at ~1 s drawn to a canvas, play badge + duration;
- text / code / Markdown / CSV — the first lines rendered as a mini page (CSV as a small table);
- audio — a waveform from `OfflineAudioContext.decodeAudioData`;
- Office files — the server rendition when the adapter returns one, otherwise a styled first-page placeholder;
- PDF — the server rendition, or the first page through **pdf.js as an optional plugin** (never bundled; Apache-2.0):
  `AC.files.plugins.pdfjs = { src: '/vendor/pdf.min.mjs', worker: '/vendor/pdf.worker.min.mjs' }` (or `AC.files.pdfjs`).
  Without either, the PDF keeps its document artwork.

The large live preview (preview pane, column view preview column, gallery stage, Quick Look) shows the full image, a video /
audio player, CSV as a table, Markdown rendered (`AC.markdown` from the `prose` module when loaded, else a built-in safe
renderer), plain text / code in monospace, and PDFs in the browser's own viewer (`<object>`, pages scroll) with a
first-page fallback where the browser has none.

## Interface
- **Toolbar**: sidebar toggle, back / forward (mirrored in RTL), breadcrumb (click a segment; click empty space,
  double-click or Ctrl+L for the editable path field), view switcher, sort & group menu, share, preview pane, Get Info,
  more menu, search (scope: this folder / everywhere; filter chips kind, date, size, tag), new folder, Upload.
- **Sidebar**: Favorites (All Files, Recents, Starred, Shared, pinned folders), Locations with usage bars, Tags (coloured
  dots, counts), Trash. Every entry is a drop target (drop on a tag = tag it, on Trash = trash it).
- **Views**: icons (custom artwork per type, live thumbnails, Persian-aware middle truncation that keeps the extension,
  icon-size slider), list (sortable + resizable columns name / date modified (Jalali in fa) / size / kind / tags / status,
  disclosure triangles that expand folders inline), columns (Miller columns + preview column), gallery (large preview +
  filmstrip). Group by kind / date / tags. Status bar: count, selection size, free space.
- **Records**: approval chip (draft / under review / approved / signed), OCR badge (+ "Run OCR" placeholder), expiry badge
  (≤ 45 days warning, expired danger) with a reminder switch; record fields (type, number, date, parties, expiry) in Get Info.
- **Get Info** (side panel ≥ 1100 px container, drawer on tablets, sheet on phones): preview, kind, size (bytes), where,
  created / modified in Jalali + Gregorian, dimensions / duration, record, tags editor, comments, sharing & permissions
  (role per person), version history with restore, activity.
- **Share dialog**: link, expiry, password switch, permission; people with access.
- **Uploads**: floating card at the bottom inline-end: per-file progress rings, pause / resume, cancel, retry, done / error
  states, overall bar, collapse; name clashes ask Replace / Keep Both / Skip (+ apply to all). Drop files from the desktop
  anywhere (onto a folder to upload into it).

## Keyboard & pointer
| Keys | Action |
|---|---|
| arrows (spatial in icons; RTL aware), Home / End, type-ahead | move; Shift extends |
| Enter, Ctrl+↓ | open · Space = Quick Look (Space / Esc closes, ← → page, + / − zoom) |
| Backspace, Alt+←, Ctrl+[ · Alt+→, Ctrl+] · Ctrl+↑ | back · forward · enclosing folder |
| F2 · Delete · Ctrl+A · Ctrl+C / X / V · Ctrl+D · Ctrl+I · Ctrl+Shift+N · Ctrl+F · Ctrl+L · Ctrl+1…4 | rename · trash (undo toast) · select all · clipboard · duplicate · info · new folder · search · path · views |
| list view → / ← (mirrored) | expand / collapse a folder |
Click, Ctrl/⌘-click, Shift-click, rubber-band marquee on empty space (Ctrl adds), double-click opens. Drag items onto
folders, breadcrumbs, sidebar entries, tags or Trash (Alt/Ctrl = copy); hovering a folder for 0.8 s springs it open.
Right-click (or long-press on tablets) opens the context menu: Open, Quick Look, Get Info, Rename, Duplicate, Compress,
Move to ▸, Copy, Cut, Copy Link, Share…, Tags ▸, Star, Move to Trash (Trash: Put Back / Delete Immediately).

## Phones and tablets
Phones (< 640 px) get a native Files-app layout: Browse screen (favorites, locations, tags as inset grouped lists), list-first
folders with a large title, back button with the previous location, a search bar that collapses on scroll, rows with
date · size · tags and record chips, swipe a row to Star / Trash, long-press to enter selection mode (checkboxes, title
"n selected", Select All / Done) with a selection bar replacing the tab bar, menus as action sheets, Quick Look full-screen
with swipe between files and swipe-down to close. Inputs are ≥ 16 px. Tablets: two panes (sidebar + view), Get Info as a drawer.

## Motion
Items stagger in on folder change; opening a folder zooms from it (back zooms out); sorting and view switches FLIP the
artwork to its new place (spring easing from `AC.motion` when present); selection highlights spring; the drag ghost lifts,
tilts and shows a count badge; Quick Look zooms from the thumbnail. With reduced motion the module keeps the fades and
drops the travel.

## Events
`ac:files:navigate {loc, entry}` · `ac:files:select {ids}` · `ac:files:open {entry}` (cancelable — default opens Quick Look) ·
`ac:files:change {action, ids}` (trash restore delete emptytrash move copy duplicate compress rename mkdir star tag) ·
`ac:files:upload {entry}`.

## i18n
Built-in fa / en / ar strings; any `fm.<key>` in the app dictionary overrides them (keys: see `S` at the top of `files.js`).
