# الگوها

الگوهای تکرارشونده‌ای که از آن‌ها صفحه می‌سازید. کدهای کامل‌تر: `skills/aramin-console/reference/recipes.md` و صفحه‌های `demo/pages/`.

## کالبد صفحه (page fragment)

هر صفحه یک قطعهٔ HTML داخل `main.ac-content` است (در دمو: `demo/pages/<name>.html`، و اگر منطق دارد `<name>.js` با `export default function mount(root, AC)`).

```html
<section class="ac-page" data-page="users" data-script>
  <header class="ac-page-head" data-ac="largetitle">
    <div class="ac-page-head__titles">
      <span class="ac-page-head__eyebrow">مدیریت</span>
      <h1 class="ac-page-head__title">کاربران</h1>
      <p class="ac-page-head__sub">فهرست و دسترسی کاربران سامانه</p>
    </div>
    <div class="ac-page-head__actions">
      <button class="ac-btn ac-btn--primary" type="button">کاربر جدید</button>
    </div>
  </header>
  <div class="ac-bento ac-stagger"> … کارت‌ها … </div>
</section>
```

قواعد: یک `h1`، یک عمل اصلی (دکمهٔ `primary` در `__actions`)، محتوا در شبکهٔ bento، کارت‌ها با `.ac-card`.

## داشبورد

1. ردیف KPI: ۳–۴ کارت `.ac-stat` (`ac-span-xs-6 ac-span-md-3`) با `data-ac="counter"`. حداکثر یکی را با `data-tone="accent"` پر کنید.
2. نمودار اصلی (`data-ac="chart"`، `ac-span-md-12 ac-span-8`) کنار فهرست کوتاه (`ac-span-4`).
3. جدول «آخرین‌ها» پایین، با پیوند «مشاهدهٔ همه».
اصل: عدد بزرگ، برچسب کوچک خاکستری، یک نشان روند (سبز/قرمز) و بس.

## صفحهٔ جدول (CRUD)

- کارت با `__body--flush` و `data-ac="table"`؛ جستجو، فیلتر، مرتب‌سازی و صفحه‌بندی داخلی‌اند.
- ستون‌ها: متن تراز ابتدا، عدد تراز انتها و `data-type="number"`، وضعیت با نشان `.ac-badge`، عمل‌ها در آخرین ستون (`ghost sm`).
- انتخاب چندتایی ← نوار عملیات گروهی (`ac:table:bulk`).
- ویرایش و ایجاد در مودال/کشو؛ حذف همیشه با `AC.confirm({ tone: 'danger' })` و سپس toast موفقیت.
- روی گوشی جدول به لیست کارتی تبدیل می‌شود (`td data-label`).

## فرم

- ستون تکی، برچسب بالای فیلد، گروه‌بندی با فاصله `--ac-s-4` و عنوان بخش.
- اعتبارسنجی با `data-ac-rules="required|iran-mobile|…"`؛ خطا کنار فیلد، پس از خروج از فیلد (نه موقع تایپ).
- دکمهٔ ثبت در انتها؛ هنگام ارسال `waitUntil(promise)` تا دکمه حالت بارگذاری بگیرد.
- فیلدهای ایرانی: موبایل/کد ملی (`ac-ltr` + `inputmode`)، تاریخ شمسی (`datepicker`)، شبا (`sheba`)، مبلغ (`money`).
- فرم‌های بلند ← `wizard` با مراحل کوتاه.
- از دست ندادن داده: قبل از بستن مودالِ تغییریافته تأیید بگیرید.

## حالت‌های خالی، خطا، بارگذاری

| حالت | الگو |
|---|---|
| **خالی** | `.ac-empty` با `__art` (آیکون)، `__title`، `__text` یک‌جمله‌ای، و `__actions` (یک دکمهٔ «ساخت …»). خالیِ نتیجهٔ جستجو: «نتیجه‌ای پیدا نشد» + پاک‌کردن فیلتر |
| **بارگذاری** | `.ac-skeleton` (`--text`، `--title`، `--block`، `--circle`) به شکل محتوای نهایی؛ نه spinner تمام‌صفحه. سپس `AC.motion.reveal()` |
| **خطای بخش** | `.ac-alert` (tone `danger`) درون همان کارت با دلیل + «تلاش دوباره» |
| **خطای صفحه** | قالب‌های `demo/errors/` (404، 500، نگهداری، آفلاین) |
| **موفقیت گذرا** | `AC.toast.success()`؛ اعلان‌های پیشرفته با `AC.notify` |

قاعده: هر لیست/جدول/نمودار سه حالت دارد (در حال بارگذاری، خالی، خطا)، نه فقط حالت پر.

## الگوهای موبایل

| الگو | رفتار |
|---|---|
| **تب‌بار** | پیل شناور پایین (`.ac-tabbar`، `data-ac="tabbar"`)، ۳–۵ مقصد، فعال = پیل ink، یک FAB اختیاری. فقط زیر ۱۰۲۴px |
| **عنوان بزرگ** | `data-ac="largetitle"`؛ هنگام اسکرول به نوار فشرده تبدیل می‌شود |
| **شیت پایین** | `AC.sheet.open` با نقطه‌های توقف؛ مودال‌ها و منوها روی گوشی خودکار شیت می‌شوند؛ با کشیدن به پایین بسته می‌شود |
| **swipe** | ردیف لیست با `data-ac="list"` اعمال کشیدنی دارد (حذف/آرشیو)؛ جهت در RTL آینه است. هر عمل swipe باید راه دیگری هم داشته باشد |
| **کشیدن برای تازه‌سازی** | `data-ac="pull-refresh"` و رویداد `ac:pull-refresh:refresh` با `waitUntil` |
| **لمس** | هدف ≥ 44px؛ `--ac-safe-bottom` برای عناصر چسبیده به پایین |
| **PWA** | ماژول `pwa`: نصب، آفلاین، به‌روزرسانی (`docs/pwa.md`) |

## ناوبری

- ریل (دسکتاپ) برای گروه‌ها و مقصدهای برنامه؛ پیل‌های بالا برای بخش‌های فضای کاری فعلی؛ پالت فرمان (`⌘K`) برای رفتن سریع.
- مقصد فعال همیشه روشن است (پیل ink)؛ نشان شمارنده با `--ac-highlight`.
- عمق بیش از دو سطح در ریل نگذارید.
