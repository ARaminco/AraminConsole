# فاصله‌گذاری و چیدمان

## مقیاس فاصله

گام پایه `0.25rem` (4px). فقط از این توکن‌ها استفاده کنید.

| توکن | rem | px |
|---|---|---|
| `--ac-s-1` | 0.25 | 4 |
| `--ac-s-2` | 0.5 | 8 |
| `--ac-s-3` | 0.75 | 12 |
| `--ac-s-4` | 1 | 16 |
| `--ac-s-5` | 1.25 | 20 |
| `--ac-s-6` | 1.5 | 24 |
| `--ac-s-8` | 2 | 32 |
| `--ac-s-10` | 2.5 | 40 |
| `--ac-s-12` | 3 | 48 |

(`--ac-s-0` صفر است؛ `--ac-s-7` `--ac-s-9` `--ac-s-11` هم موجودند.)

راهنما: درون کنترل ۲–۳، بین عناصر مرتبط ۲–۴، بین کارت‌ها `--ac-gap` (۱۶px)، بین بخش‌های صفحه ۶–۸.

## توکن‌های وابسته به تراکم

`data-density="compact"` این‌ها را کوچک می‌کند:

| توکن | راحت | فشرده |
|---|---|---|
| `--ac-control-h` | 2.5rem | 2.125rem |
| `--ac-card-pad` | 1.25rem | 0.95rem |
| `--ac-row-h` | 3.25rem | 2.625rem |
| `--ac-gap` | 1rem | 0.75rem |
| `--ac-fs-md` | 0.875rem | 0.8125rem |

با `--ac-touch` (44px) کمینهٔ هدف لمسی را همیشه رعایت کنید؛ در تراکم فشرده هم روی موبایل.

کلاس‌های کمکی چیدمان: `ac-stack` (عمودی)، `ac-cluster` (افقی شکسته)، `ac-row`، `ac-spread` (دو سر)، `ac-grid`، و `ac-gap-N`.

## شبکهٔ bento

شبکهٔ ۱۲ ستونی `.ac-bento`. فرزندان به‌صورت پیش‌فرض کل عرض را می‌گیرند.

| کلاس | از | کار |
|---|---|---|
| `ac-span-xs-6` | گوشی | نیم‌عرض |
| `ac-span-md-3/4/6/8/12` | ≥ 640px | بازهٔ تبلت |
| `ac-span-2…9، 12` | ≥ 1024px | دسکتاپ |
| `ac-span-xl-*` | ≥ 1280px | صفحهٔ عریض |

```html
<div class="ac-bento ac-stagger">
  <article class="ac-card ac-span-xs-6 ac-span-md-4 ac-span-3">KPI</article>
  <article class="ac-card ac-span-md-12 ac-span-9">نمودار</article>
</div>
```

`.ac-stagger` ورود پله‌ای کارت‌ها را فعال می‌کند. اندازهٔ کارت‌ها را بر اساس اهمیت تغییر دهید؛ همه‌چیز هم‌اندازه نباشد.

## نقاط شکست

| محدوده | چیدمان |
|---|---|
| < 640px (گوشی) | تب‌بار شناور پایین، عنوان بزرگ جمع‌شونده، شیت‌ها، ستون تکی/دوتایی |
| 640–1023px (تبلت) | نوار بالا فشرده، ریل پنهان، تب‌بار پایین |
| ≥ 1024px (دسکتاپ) | ریل باریک کنار شروع + پیل‌های بالا، فلای‌اوت گروه‌ها |
| ≥ 1280px | ستون‌های `ac-span-xl-*` |

کلاس‌های نمایش: `ac-hide-phone`، `ac-hide-mobile`، `ac-hide-desktop`.

## ناحیهٔ امن (Safe area)

`--ac-safe-top/bottom/start/end` از `env(safe-area-inset-*)` می‌آیند. برای کار روی گوشی‌های دارای ناچ:

- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">` الزامی است.
- هر چیز چسبیده به لبهٔ پایین (تب‌بار، FAB، نوار عمل) باید `--ac-safe-bottom` را اضافه کند؛ مثل `bottom: calc(var(--ac-tabbar-h) + var(--ac-safe-bottom) + var(--ac-s-6))`.
- ویژگی‌های منطقی را به کار ببرید: `inset-inline-start`، `padding-inline-end`.
