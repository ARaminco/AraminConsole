# آیکون‌ها

آیکون‌ها از [Lucide](https://lucide.dev) (مجوز ISC) هستند و در قالب یک **اسپرایت SVG** (`dist/icons.svg`) عرضه می‌شوند.

## استفاده

```html
<html data-ac-icons="/aramin/icons.svg">
…
<svg class="ac-icon" aria-hidden="true"><use href="#i-house"/></svg>
```

- شناسه همیشه `#i-<نام-lucide>` است (مثل `#i-circle-help`، `#i-chart-line`).
- آیکونِ تزئینی `aria-hidden="true"`. آیکونِ تنها (دکمهٔ آیکونی) حتماً `aria-label` روی دکمه داشته باشد.
- اندازه و رنگ با CSS می‌آید: رنگ از `currentColor` ارث می‌برد؛ اندازه با `.ac-icon` (و گونه‌های اندازه در CSS).
- ضخامت خط و سبک را عوض نکنید؛ یکدست می‌ماند.

## فقط آیکون‌های موجود

اسپرایت فقط آیکون‌های فهرست `src/icons/icons.txt` را دارد (بیش از ۳۰۰ آیکون). برای آیکون تازه:

1. نام Lucide را به `src/icons/icons.txt` اضافه کنید (هر نام در یک خط)، یا فایل `src/icons/<name>.svg` سفارشی بگذارید.
2. `npm run build` را اجرا کنید.

صفحهٔ «سیستم طراحی» در دمو شبکهٔ جستجوپذیر همهٔ آیکون‌هاست.

## وارونگی در RTL

آیکون‌هایی که «جهت» دارند باید در RTL آینه شوند: کلاس `.ac-flip-rtl` (در `[dir="rtl"]` معادل `scaleX(-1)`).

| وارونه شود | وارونه نشود |
|---|---|
| فلش‌های «بعدی/قبلی»، chevron ناوبری، خروج (`log-out`)، آیکون‌های پنل جانبی، «بازگشت» | بالا/پایین، `plus`، `check`، `x`، ساعت، آیکون‌های متقارن، لوگوها |

نشانگر روند (`.ac-trend`)، صفحه‌بندی و ناوبری تقویم خودکار وارونه می‌شوند.

```html
<svg class="ac-icon ac-flip-rtl" aria-hidden="true"><use href="#i-chevron-right"/></svg>
```

## راهنما

- یک مفهوم = یک آیکون در کل محصول (کاربر همیشه `users`، سفارش همیشه `shopping-cart`).
- آیکون بدون متن فقط وقتی مفهوم عام است (جستجو، بستن، اعلان). غیر از آن همراه برچسب.
- ایموجی در رابط استفاده نمی‌شود (در ویندوز یکدست رندر نمی‌شود).
