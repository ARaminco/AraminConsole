# تایپوگرافی

## قلم

| توکن | مقدار | کاربرد |
|---|---|---|
| `--ac-font` | `Vazirmatn`، سپس قلم‌های سیستم | رابط فارسی/عربی (پیش‌فرض) |
| `--ac-font` در `:lang(en)` | `Inter`، `Segoe UI Variable Text`، … و Vazirmatn به‌عنوان پشتیبان | رابط انگلیسی |
| `--ac-font-mono` | `ui-monospace`، `Cascadia Code`، … | کد، شناسه، لاگ |

قلم‌ها در `dist/fonts` هستند و باید کنار CSS کپی شوند. هنگام تغییر قلم، `--ac-font` را در فایل برند بازنویسی کنید (← [brand.md](brand.md)).

## مقیاس اندازه

| توکن | اندازه | نقش |
|---|---|---|
| `--ac-fs-2xs` | 11px | نشان‌های ریز |
| `--ac-fs-xs` | 12px | برچسب، کمکی |
| `--ac-fs-sm` | 13px | متن ثانویه، سلول جدول فشرده |
| `--ac-fs-md` | 14px | **متن بدنه** (در تراکم فشرده 13px) |
| `--ac-fs-lg` | 16px | متن درشت، ورودی روی موبایل |
| `--ac-fs-xl` | 18px | تیتر کارت |
| `--ac-fs-2xl` | 22px | تیتر بخش |
| `--ac-fs-3xl` | 28px | تیتر صفحه |
| `--ac-fs-4xl` | 36px | عدد قهرمان (KPI بزرگ) |

ارتفاع خط: `--ac-lh-tight` (1.2) برای تیتر و عدد، `--ac-lh-snug` (1.4) برای عنوان چندخطی، `--ac-lh-normal` (1.65) برای متن. فارسی به ارتفاع خط بیشتری نیاز دارد؛ متن بدنه را زیر 1.5 نبرید.

## وزن‌ها

`--ac-fw-regular` 400 · `--ac-fw-medium` 500 · `--ac-fw-semibold` 600 · `--ac-fw-bold` 700 · `--ac-fw-black` 800.

قاعدهٔ سرانگشتی: تیترها `semibold` (نه سنگین)، برچسب‌ها `medium`، متن `regular`. `black` فقط برای عدد قهرمان.

## سلسله‌مراتب

| سطح | اندازه / وزن | رنگ |
|---|---|---|
| عنوان صفحه (`.ac-page-head__title`) | `3xl` / semibold | `--ac-text` |
| زیرعنوان (`__sub`) | `md` | `--ac-muted` |
| تیتر کارت | `xl` / semibold | `--ac-text` |
| برچسب (`.ac-stat__label`) | `xs`–`sm` / medium | `--ac-muted` |
| عدد KPI (`.ac-stat__value`) | `3xl`–`4xl` / semibold، tabular | `--ac-text` |

## اعداد و ارقام

- **پیش‌فرض: ارقام لاتین** (`0-9`) حتی در رابط فارسی. با `AC.i18n.setDigits('native')` یا سوییچ «ارقام» در سفارشی‌ساز، ارقام فارسی روشن می‌شوند (کلید ذخیره: `ac:digits`).
- عددهای جدول و KPI **هم‌عرض** (tabular) هستند تا ستون‌ها تراز بمانند؛ کلاس `.ac-num`.
- عددهای جداکننده‌دار با `AC.format.number` یا `AC.money.format` قالب شوند؛ دستی ویرگول نگذارید.
- تاریخ شمسی: `AC.date.format(d, { calendar: 'persian' })`.
- یک سیاست را در کل محصول نگه دارید: یا همه لاتین یا همه فارسی. ترکیب نکنید.
- شماره کارت، شبا، ایمیل، کد و مسیر فایل داخل متن RTL با `.ac-ltr` یا `<bdi>` ایزوله شوند. ← [rtl-i18n.md](rtl-i18n.md)

## کوتاه‌نویسی‌ها

- نیم‌فاصله (ZWNJ) در «می‌شود»، «پرسش‌های»، «کامپوننت‌ها» رعایت شود.
- «ی» و «ک» فارسی (نه ي و ك عربی). جستجوها باید هر دو را یکی کنند (نمونه: `demo/pages/faq.js`).
- حروف بزرگ و کوچک لاتین (`UPPERCASE`) روی فارسی بی‌معنی است؛ برای تأکید از وزن استفاده کنید.
- زیرخط‌دار کردن متن فارسی را فقط برای پیوند نگه دارید.
