# گوشه، سایه و لایه‌ها

## شعاع گوشه

| توکن | پیش‌فرض | کاربرد |
|---|---|---|
| `--ac-r-xs` | 6px | چیپ کوچک |
| `--ac-r-sm` | 10px | ورودی‌های ریز |
| `--ac-r-md` | 12px | دکمه، ورودی |
| `--ac-r-lg` | 16px | پنل‌های داخلی |
| `--ac-r-xl` | 22px | **کارت** |
| `--ac-r-2xl` | 28px | فلای‌اوت و شیت |
| `--ac-r-pill` | 999px | پیل: دکمه‌های اصلی، فیلد جستجو، چیپ |

`data-radius="sharp"` همهٔ این‌ها را به ۲–۱۰px و `data-radius="round"` به ۸–۳۲px می‌برد (جدول در [tokens.md](tokens.md)). **قاعدهٔ تودرتو:** گوشهٔ عنصر داخلی کوچک‌تر از والد باشد (کارت `xl` ← پنل داخلی `lg` ← کنترل `md`).

## سایه (ارتفاع)

سایه‌ها عمداً کم‌اند؛ مرز مویی کار اصلی را می‌کند.

| توکن | کاربرد |
|---|---|
| `--ac-shadow-xs` | کارت ساکن |
| `--ac-shadow-sm` | کارت |
| `--ac-shadow-md` | hover کارت، منو |
| `--ac-shadow-lg` | پاپ‌اور، فلای‌اوت |
| `--ac-shadow-xl` | مودال، شیت |
| `--ac-shadow-chrome` | پیل‌های شناور (نوار بالا، ریل، تب‌بار) |
| `--ac-shadow-glow` | درخشش رنگ برند (دکمهٔ رنگی/FAB) |
| `--ac-shadow-inset` | برجستگی داخلی ظریف |

قاعده: ارتفاع بیشتر = اهمیت یا موقتی‌بودن بیشتر (مودال از کارت بالاتر است). روی عناصر هم‌سطح سایهٔ متفاوت نگذارید. در تم تیره سایه‌ها تیره‌ترند اما مرز، جداکنندهٔ اصلی است.

## لایه‌ها (z-index)

هرگز عدد خام ننویسید؛ از توکن استفاده کنید. ترتیب از پایین به بالا:

| توکن | مقدار | عنصر |
|---|---|---|
| `--ac-z-base` | 1 | محتوا |
| `--ac-z-sticky` | 20 | سرستون چسبان |
| `--ac-z-rail` | 40 | ریل |
| `--ac-z-appbar` | 50 | نوار بالا |
| `--ac-z-tabbar` | 55 | تب‌بار |
| `--ac-z-dropdown` | 60 | منو و دراپ‌داون |
| `--ac-z-drawer` | 70 | کشو |
| `--ac-z-sheet` | 80 | شیت پایین |
| `--ac-z-modal` | 90 | مودال |
| `--ac-z-toast` | 100 | اعلان گذرا |
| `--ac-z-palette` | 110 | پالت فرمان |
| `--ac-z-tooltip` | 120 | راهنمای شناور |

مودال‌ها، شیت‌ها و منوها را با `AC.modal`، `AC.sheet`، `AC.dropdown` باز کنید؛ پشتهٔ لایه‌ها، تله‌ی فوکوس و بستن با Esc را خودشان مدیریت می‌کنند (`docs/overlays.md`).
