آکاردئون

data-ac="accordion" data-single

آیا AraminConsole وابستگی دارد؟
خیر؛ یک فایل CSS و یک ماژول JS، بدون هیچ وابستگی.
تقویم شمسی پشتیبانی می‌شود؟
بله؛ تاریخ‌ها در فارسی شمسی نمایش داده می‌شوند و انتخاب‌گر تاریخ هر دو تقویم را دارد.
در Laravel Blade کار می‌کند؟
بله؛ CSS و ماژول را اضافه کنید و از ویژگی‌های data-ac استفاده کنید.
