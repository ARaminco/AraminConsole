# طراحی پنل مدیریتی راست‌به‌چپ؛ از تایپوگرافی تا انیمیشن

پنل مدیریتی خوب فقط «کار می‌کند» نیست؛ **خوانا** است، *سریع* حس می‌شود و روی گوشی مثل یک اپ رفتار می‌کند. در این نوشته، تجربهٔ ساخت **AraminConsole** را مرور می‌کنیم: از اندازهٔ سطرها تا جزئیات کوچکی مثل جهت متن در جمله‌هایی که فارسی و English را با هم دارند.

> [!NOTE]
> این مقاله با ماژول `prose` و مبدل Markdown بدون وابستگی ساخته شده است. همهٔ عنصرهایی که اینجا می‌بینید، از همین فایل Markdown تولید شده‌اند.

## چرا راست‌به‌چپ از پایه؟

بیشتر قالب‌های مدیریتی اول برای انگلیسی طراحی می‌شوند و بعد «برعکس» می‌شوند. نتیجه معمولاً آیکون‌های برعکس، فاصله‌های نادرست و اعدادی است که وسط جمله جابه‌جا می‌شوند. ما از همان ابتدا فقط از **ویژگی‌های منطقی CSS** استفاده کردیم: `margin-inline-start` به‌جای `margin-left` و `inset-inline-end` به‌جای `right`.

### سه قاعدهٔ ساده

1. هیچ‌وقت جهت را حدس نزنید؛ از `dir` و ویژگی‌های منطقی استفاده کنید.
2. اعداد، کد و نشانی‌ها را جدا کنید (`<bdi>` یا `unicode-bidi: isolate`).
3. هر پاراگراف جهت خودش را از اولین حرفش بگیرد:
   - جملهٔ فارسی، راست‌چین
   - an English sentence stays left-aligned
   - و فهرست‌های تودرتو هم درست می‌مانند
     1. سطح سوم با شماره
     2. و یک مورد دیگر

This paragraph is written in English inside a Persian article. With `unicode-bidi: plaintext`, it aligns to the left and its punctuation stays where English readers expect it.

## اندازهٔ سطر و ریتم متن

طول مناسب سطر برای خواندن بین ۶۰ تا ۷۵ نویسه است. سطرهای بلندتر چشم را خسته می‌کنند و سطرهای کوتاه‌تر ریتم را می‌شکنند. برای فونت وزیرمتن، ارتفاع سطر حدود `1.9` بهترین نتیجه را داد؛ برای متن انگلیسی کمی کمتر.

| ویژگی | فارسی | English | توضیح |
|:------|:-----:|:-------:|------:|
| ارتفاع سطر | 1.95 | 1.75 | فارسی به فضای بیشتری نیاز دارد |
| طول سطر | 70ch | 70ch | حدود ۱۲ کلمه |
| اندازهٔ متن | 17px | 17px | روی گوشی هم خوانا |
| وزن تیترها | 600 | 600 | نیمه‌ضخیم، نه سیاه |

> طراحی خوب مثل یک پیشخدمت خوب است؛ وقتی کارش را درست انجام می‌دهد، دیده نمی‌شود.
>
> — از یادداشت‌های تیم طراحی

## کد و میان‌برها

بلوک‌های کد همیشه چپ‌به‌راست هستند، حتی وسط متن فارسی. دکمهٔ کپی و برچسب زبان هم خودکار اضافه می‌شوند:

```js
import { AC } from 'aramin-console';

// تبدیل Markdown به HTML امن
const html = AC.markdown('# سلام **دنیا**');
document.querySelector('#post').innerHTML = html;
```

```php
<?php
// همان کار در سمت سرور: خروجی امن را در قالب قرار دهید
echo view('post', ['html' => $markdown->render($post->body)]);
```

برای باز کردن جست‌وجوی سریع، کلید <kbd>Ctrl</kbd> + <kbd>K</kbd> را بزنید؛ روی مک <kbd>⌘</kbd> + <kbd>K</kbd>. فرمول آب H<sub>2</sub>O است و مساحت دایره πr<sup>2</sup>.

## هشدارها و نکته‌ها

> [!TIP]
> برای مقاله‌های طولانی، فهرست مطالب را روشن نگه دارید. کاربران موبایل آن را بالای صفحه به‌صورت جمع‌شونده می‌بینند.

> [!IMPORTANT] پیش از انتشار
> متن را با هر سه زبان فارسی، English و العربية بررسی کنید.

> [!WARNING]
> HTML خام در Markdown به‌صورت متن نمایش داده می‌شود. این عمداً برای جلوگیری از حملهٔ XSS است: `<script>alert(1)</script>` اجرا نمی‌شود.

> [!CAUTION]
> پیوندهای `javascript:` حذف می‌شوند؛ مثلاً [این پیوند](javascript:alert(1)) فقط متن است.

:::details پرسش متداول: آیا HTML خام پشتیبانی می‌شود؟
خیر. فقط چند برچسب ساده و بدون ویژگی مثل `<kbd>`، `<sub>`، `<sup>` و `<mark>` مجازند. اگر واقعاً به HTML نیاز دارید، آن را جداگانه پاک‌سازی کنید.
:::
